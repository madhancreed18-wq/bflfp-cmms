TECHNICIAN PHOTOS  —  for the daily shift-plan report and the app.

WHERE TO SAVE
  E:\github-projects\bflfp-cmms\static\techphotos\

FILE NAME  =  the technician's NAME (as in Admin -> Users) + .jpg or .png
  Examples:
    ศิริโชค หล้าหิบ.jpg
    ทัศน์พล สำราญดี.jpg
    กัญญา มณีสังข์.png

The app selects the photo automatically by the technician's name.
If there is no matching file, the report shows the person's initials instead.

MATCHING (kept forgiving)
  - Use the core name. You may leave OUT the title ("นาย / นาง / นางสาว")
    and any nickname in brackets "(โชค)". Spaces and upper/lower don't matter.
    So for "นาย ศิริโชค หล้าหิบ (โชค)" just save:  ศิริโชค หล้าหิบ.jpg
  - If a photo doesn't appear, it's almost always a spelling difference from
    the name in Admin -> Users — make the two match.

TIPS
  - Square-ish photo, about 300 x 300 px, .jpg or .png.
  - Add or replace any time; drop the file here and refresh.
