How it works
  • Today: a saved OK/NG answer points to the checklist item. Re-uploading the Excel deletes and recreates the items, so past answers lose their item (FP live: 481 answers at risk).
  • New: each answer also stores the item's wording, number and frequency at the moment it was answered.
  • Records, PM report PDFs and the PM report list read that stored wording, so they never change.
  • Existing 481 FP answers get their wording copied in on first start, before any upload can touch them.

Please decide before I build

A. PM job already started when the sheet is edited.
Proposal: a job that has started keeps the list it started with; jobs not yet started get the new list. So a technician mid-round is never suddenly blocked by a new item.
B. Who can edit.
Proposal: planner (only their own factory) and admin (the factory selected at login). Manager and technician: view only.
C. Excel vs app.
Proposal: both allowed; the last one saved wins, and the upload warns (as in step 4) when it overwrites an in-app edit.
