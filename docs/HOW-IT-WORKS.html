🙋 Operator / หัวหน้าไลน์ ใช้เวลา ~5 นาที/วัน

ทำอะไรบ้าง
  1. เจอปัญหาเครื่อง → เปิดแอป เลือกเครื่อง พิมพ์อาการ เลือกความเร่งด่วน กดส่ง
  2. เครื่องหยุดกะทันหัน → เลือก ด่วน! — ช่างทุกคนได้แจ้งเตือนทันที ไม่ต้องวิ่งตามหา
  3. งานมีค่าใช้จ่าย → ติ๊ก "ขออนุมัติ" ระบบส่งเข้าคิวอนุมัติเอง
  4. ท้ายกะ → กรอกผลผลิต 3 ช่อง/เครื่อง (เวลาแผน, ผลิตได้, ของดี) — 2 นาที
สิ่งที่ได้กลับ: เห็นสถานะงานที่แจ้งตลอดเวลา (ใครรับ ซ่อมถึงไหน เสร็จหรือยัง) ไม่ต้องเดินไปถาม · ทุกใบแจ้งมีเลขที่ PRD ติดตามได้ · ผลผลิตที่กรอกกลายเป็น OEE ของไลน์อัตโนมัติ

🗓 Planner / ผู้วางแผน ศูนย์กลางของระบบ

ทำอะไรบ้าง
  1. เช้า: เปิดแอป — งาน PM ที่ถึงรอบสร้างตัวเองอัตโนมัติแล้ว
  2. ดูแท็บ Recent / OverDue / DueToday → กด Plan ที่การ์ดงาน → เลือกวัน เวลา ช่างหลัก ผู้ช่วย → ปล่อยงาน (ช่างได้แจ้งเตือนทันที)
  3. งานขออนุมัติ → กดอนุมัติ/ไม่อนุมัติ พร้อมเหตุผล
  4. งานที่ช่างทำเสร็จ → ตรวจรับ: คำถาม 2 ข้อ (แก้เรียบร้อย? เคลียร์พื้นที่?) → ผ่าน = Done / ไม่ผ่าน = Rework หรือออกใบใหม่
  5. วางกิจกรรม 📌 (สั่งอะไหล่, โทร supplier) มอบให้ใครก็ได้ พร้อมกำหนดเสร็จ
สิ่งที่ได้กลับ: เห็นงานทั้งโรงงานในจอเดียว ไม่มีงานหลุด (OverDue เตือนเอง) · เฉพาะงานที่ปล่อยแล้วเท่านั้นที่นับใน % ของแผน — แผนยุติธรรม · ประวัติทุกการตัดสินใจอยู่ในไทม์ไลน์งาน

🔧 ช่างซ่อมบำรุง มือถือเครื่องเดียวจบ

ทำอะไรบ้าง
  1. เปิดแอป → งานของฉันวันนี้ เรียงตามเวลา
  2. เริ่มงาน กด ▶ — นาฬิกาเดินเอง ไม่ต้องจดเวลา
  3. โดนเรียกไปงานด่วน → กด ⏸ เลือกเหตุผล (Breakdown แทรก / รออะไหล่ / รอผลิต) — เวลางานเดิมไม่หาย กลับมากด ▶ ต่อได้
  4. เสร็จ กด ✅ → กรอกปัญหา-สาเหตุ-วิธีแก้ + เลือกรหัสชิ้นส่วนที่เสีย (2 dropdown) + ถ่ายรูปก่อน-หลัง + เซ็นชื่อบนจอ
  5. งาน routine / standby ก็กดบันทึกเวลาได้ — เวลาทั้งวันมีค่า ไม่หาย
  6. 💬 สงสัยอะไร ถามในงานเลย — คำตอบติดอยู่กับใบงานตลอดไป
สิ่งที่ได้กลับ: ไม่ต้องเขียนกระดาษ ไม่ต้องนั่งทำรายงานท้ายวัน — PDF ใบแจ้งซ่อมสร้างเอง · เวลา "รออะไหล่" แยกจากเวลาซ่อมจริง → MTTR ยุติธรรมกับช่าง · ประวัติเครื่องอยู่ในมือ ก่อนไปหน้างานรู้เลยเครื่องนี้เคยเป็นอะไร

📊 ผู้จัดการ เปิดดู ไม่ต้องกรอกอะไร

ทำอะไรบ้าง
  1. เย็น: เปิด Dashboard — 3 เปอร์เซ็นต์ (แผนสำเร็จ / Breakdown ปิดได้ / รวม)
  2. ดู Gantt: ช่างแต่ละคนใช้เวลากับอะไรทั้งวัน — สีบอกทุกอย่าง
  3. ดู OEE / MTBF / MTTR รายเครื่อง เทียบเป้ามาตรฐาน (สีเขียว/แดงตัดสินให้)
  4. งานค้างพร้อมเหตุผล — ไม่ต้องเรียกประชุมถาม
  5. กด 🖨 รายงานประจำวัน PDF ส่งต่อผู้บริหารได้เลย
สิ่งที่ได้กลับ: ตอบได้ทุกเช้าว่า "เมื่อวานเสียกี่ครั้ง เสียเวลาไปเท่าไหร่ เพราะชิ้นส่วนอะไร ใครซ่อม นานแค่ไหน" ด้วยข้อมูลจริง ไม่ใช่ความรู้สึก · เห็นแนวโน้ม 14 วันว่าดีขึ้นหรือแย่ลง

  2. เพิ่มผู้ใช้ กำหนดบทบาท รีเซ็ตรหัสผ่าน ปิดบัญชีคนลาออก
สิ่งที่ได้กลับ: ระบบดูแลตัวเอง — PM สร้างเองตามรอบ ข้อมูลถูกบังคับให้ครบตั้งแต่ต้นทาง ไม่ต้องตามแก้ทีหลัง

⚖️ กติกาเหล็ก 3 ข้อ (ทำไมตัวเลขของเราเชื่อถือได้)

  • ไม่กดจับเวลา = ปิดงานไม่ได้ — เวลาทุกนาทีมาจากการกดจริง ไม่ใช่นั่งนึกย้อนหลัง

  • ไม่กรอกผลผลิต = เครื่องนั้นขึ้น "ไม่มีข้อมูล" — ไม่มีตัวเลขปลอม 100%
